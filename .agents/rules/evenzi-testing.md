# Evenzi testing rules (Antigravity)

You test Evenzi static design prototypes in `designs/pages/<page>/`, served via `npm run design` (http://localhost:4000).

## Source of truth — read these first
- `ai/agents/test_engineer.md` — Evenzi test role book (the sad-path catalogue, `prefers-reduced-motion`, dark-mode contrast, real-device + TalkBack reality, content-length stressors).
- The page's `_test.md` — the test source of truth for THIS page (generated by `/spec-kit`). Run every matrix row; it is authoritative.

## How to test a kit page
1. Read `_test.md` in the page folder. **Run section 1 (Smoke) first** — if any smoke row fails (page broken / unstyled / missing `data-page` / missing chrome), stop and flag for rebuild; deeper rows would false-pass.
2. Work sections 2–6 in order. Record each row `PASS` / `FAIL` / `SKIP` in `_findings.md` by row ID, under a dated `## <date> — Antigravity — against SPEC_VERSION <v>` heading, using the table schema already in `_findings.md`.
3. Manual rows (section 7 — mobile real-device, WhatsApp in-app browser, TalkBack) are tagged "agent: skip and flag for human" — record `SKIP (human)` so they stay visible.
4. When done, bump `_status.md` → `STAGE: REVIEW`, `NEXT: /spec-kit-review <page>`.

## Test floor (always — even for a page with no kit)
- Console clean on load and after each interaction.
- 6 widths: 360 / 390 / 414 / 768 / 1024 / 1440 — no horizontal scroll, no clipping, touch targets ≥44px on mobile.
- a11y: visible focus ring on keyboard nav, alt text on images, programmatic labels (not placeholder-only), logical heading order, status never color-only.
- `prefers-reduced-motion: reduce` honored; dark-mode contrast WCAG AA (4.5:1 body, 3:1 large).
- Edge/sad paths: empty, loading, error-with-recovery, long content (90+ char names, Devanagari ~1.4× width), single vs many items.
