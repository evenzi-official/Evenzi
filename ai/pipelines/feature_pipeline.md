## Feature Development Pipeline

### Step 1: Product Manager

* Define feature
* Create user flow
* Identify requirements

OUTPUT:

* Feature specification
* API needs
* UI expectations

---

### Step 2: Tech Lead

* Convert feature into technical design
* Define architecture
* Identify modules

OUTPUT:

* System design
* Folder structure impact
* Data model

---

### Step 3: Task Distributor

* Break feature into tasks

OUTPUT:

* Backend tasks
* Frontend tasks
* Integration tasks
* Testing tasks

---

### Step 4: Engineers

* Backend Engineer → APIs + DB
* Frontend Engineer → UI
* Fullstack → integration

---

### Step 5: Code Reviewer

* Improve quality
* Fix issues
* Optimize

---

### Step 6: QA Engineer

* Generate test cases
* Validate edge cases
