## Bug Fix Pipeline

### Step 1: Identify Issue

* Understand bug clearly
* Gather context

### Step 2: Reproduce

* Identify steps to reproduce
* Confirm consistency

### Step 3: Root Cause Analysis

* Find actual issue
* Avoid surface fixes

### Step 4: Fix

* Apply minimal and correct fix
* Avoid breaking existing logic

### Step 5: Validate

* Test scenarios
* Ensure no regression

### Step 6: QA

* Add test cases
* Validate edge cases

## Output

* Bug explanation
* Fix implementation
* Test cases
