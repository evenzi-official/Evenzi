## Release Preparation Workflow

### Step 1: Feature Completion

* Ensure all features are implemented

### Step 2: Code Review

* Final review done

### Step 3: QA Validation

* All test cases passed

### Step 4: Env Setup

* Check environment variables
* Verify Supabase & R2 configs

### Step 5: Build Check

* Ensure Next.js build passes

### Step 6: Deployment

* Deploy via Vercel

### Step 7: Post-Deployment Check

* Verify APIs
* Verify UI
* Check logs

## Output

* Release readiness status
* Deployment checklist
