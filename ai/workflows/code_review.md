## Code Review Workflow

### Step 1: Understand Code

* Read full implementation

### Step 2: Check Quality

* Readability
* Naming
* Structure

### Step 3: Check Architecture

* Separation of concerns
* Modularity

### Step 4: Check Performance

* DB queries
* Loops
* API calls

### Step 5: Check Security

* Input validation
* Auth handling

### Step 6: Suggest Improvements

* Refactor if needed

## Output

* Issues
* Improvements
* Refactored code (optional)
