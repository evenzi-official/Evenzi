## General Naming Rules

### Files & Folders

* Use kebab-case
* Example: event-management, user-service

### Variables & Functions

* camelCase
* Example: getUserEvents, createInvitation

### Components

* PascalCase
* Example: EventCard, InvitationList

### Constants

* UPPER_CASE
* Example: MAX_RETRY_COUNT

### API Routes

* Use plural nouns
* Example:

  * /api/events
  * /api/invitations

### Database Tables (Supabase)

* snake_case
* Example:

  * events
  * event_members
  * invitations

### Columns

* snake_case
* Example:

  * created_at
  * event_id

## Principles

* Names must be descriptive
* Avoid abbreviations
* Keep consistency across project
