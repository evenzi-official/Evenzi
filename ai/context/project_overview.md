## Project: Evenzi

A modular event management platform built using Next.js and Supabase.

## Users

* Event Hosts
* Event Management Organizations

## Core Features

* Event creation
* Invitations
* Budgeting
* Task & milestones
* Multi-event dashboard

## Key Architecture

* Next.js fullstack (UI + API)
* Supabase (database + authentication)
* Cloudflare R2 (file storage)

## Key Idea

Users can enable/disable features per event.
