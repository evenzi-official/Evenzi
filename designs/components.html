B9 · Segmented Control · view-mode filter (no panels)

The .nav-tabs primitive is visual; pick the role to match the semantics. Use role="tablist" + role="tab" + aria-selected when each button maps to a tabpanel (the live nav at top of this page is one). Use role="radiogroup" + role="radio" + aria-checked for filters / view-mode toggles like this one — see FF8 for stacked variant.

B10 · Google OAuth button · default · hover · loading

Use .btn-google for OAuth sign-in surfaces. Inline 4-color "G" SVG (Google brand requires no recoloring). Same height as .btn-pill-lg (46px). Full-width by default. Loading state shares .btn-pill-spinner child + .is-loading + aria-busy="true".

B11 · "or" divider · between two action paths

or

Use .divider-or to separate two equal-weight action paths (e.g. OTP vs OAuth, email vs phone, etc.). Rule color var(--brand-tint-2) for AA contrast in dark mode.

B12 · Auth tabs · .nav-tabs.auth-tabs · in-card 2-state segmented

.auth-tabs is a modifier on .nav-tabs tuned for in-card mode-switching — full-width, no backdrop blur (parent card is opaque), quieter inactive-hover so it doesn't compete with the active state. Semantics: role="radiogroup" + role="radio" + aria-checked. Reuse on any auth / mode-switch surface.

B13 · Coming-soon tag · .role-tag-soon · roadmap marker

Coming soon

Small chip used inside radio-pills, cards, etc. to flag roadmap items that aren't live yet. Brand-tinted, AA contrast, tracked-out caps to match the eyebrow language.
