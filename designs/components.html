15 · React wrapper map

components/ui/* → shell primitives

Each React wrapper in components/ui/ must emit the canonical shell markup above — nothing invented. This table is the contract; if a wrapper drifts from the class on the right, it renders unstyled. Keep both in sync in the same change (Reuse-Before-Create).

RW1 · <Button> · components/ui/Button.tsx

Emits .btn-pill + variant + size. variant → primary=.btn-pill-primary, secondary=.btn-pill-secondary, danger=.btn-pill-danger, ghost=.btn-pill-ghost. size → sm=.btn-pill-sm, md=base, lg=.btn-pill-lg. loading → .is-loading + .btn-pill-spinner child. See B2.

RW2 · <ToggleSwitch> · components/ui/ToggleSwitch.tsx

Emits <button class="toggle-switch" role="switch" aria-checked><span class="toggle-switch-thumb"/></button> (see B8). On-state is driven by aria-checked="true" — never a CSS class. Supports controlled (checked+onChange) and uncontrolled (defaultChecked) use. Optional label wraps with .toggle-switch-row + .toggle-switch-label.

RW3 · <StatusBadge> · components/ui/StatusBadge.tsx

Emits .status-badge + a real status class (see P5). variant → success=.status-confirmed, warning=.status-maybe, danger/overrun=.status-declined, info/live=.status-published, draft=.status-draft. dot → adds .status-dot.
